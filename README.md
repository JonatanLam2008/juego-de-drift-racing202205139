que dice Requerimientos funcionales 

1. Registro de usuarios: El sistema debe permitir a los jugadores crear una cuenta mediante un nombre de usuario, correo electrónico y contraseña. 

2. Inicio de sesión: El sistema debe permitir a los usuarios iniciar y cerrar sesión. 

3. Perfil del jugador: El sistema debe permitir consultar información del jugador, como nombre, nivel, victorias, derrotas y puntuaciones. 

4. Selección de vehículo: El jugador debe poder seleccionar un carro antes de comenzar una carrera. 

5. Personalización: El sistema debe permitir modificar características visuales del carro, como color, diseño y accesorios. 

6. Selección de pista: El jugador debe poder seleccionar entre diferentes pistas disponibles. 

7. Crear una carrera online: Un jugador debe poder crear una sala de carrera e invitar o permitir que otros jugadores se unan. 

8. Unirse a una carrera: El sistema debe permitir que los jugadores se unan a una sala disponible. 

9. Emparejamiento: El sistema puede ofrecer un mecanismo para encontrar automáticamente otros jugadores disponibles con un nivel similar. 

10. Inicio de carrera: El sistema debe iniciar la carrera cuando se cumplan las condiciones establecidas, por ejemplo, cuando haya suficientes jugadores. 

11. Movimiento del vehículo: Durante la carrera, el jugador debe poder acelerar, frenar, girar y utilizar otras acciones relacionadas con la conducción. 

12. Sincronización online: El sistema debe transmitir y actualizar en tiempo real la posición y acciones de los vehículos de los diferentes jugadores. 

13. Sistema de colisiones: El juego debe detectar las colisiones entre vehículos y elementos de la pista. 

14. Finalización de carrera: El sistema debe determinar automáticamente el orden de llegada de los participantes. 

15. Resultados: Al finalizar una carrera, el sistema debe mostrar los resultados y las posiciones obtenidas. 

16. Sistema de puntuación: El sistema debe asignar puntos, experiencia o recompensas según el resultado de cada carrera. 

17. Clasificación: El sistema debe permitir consultar una tabla de posiciones o ranking de los jugadores.
